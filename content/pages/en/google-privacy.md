Last updated: October 16, 2026.

This policy covers a private OAuth client named "RClone", created and used only by Josenaldo Matos to sync his own files between his own computer and his own Google Drive with [rclone](https://rclone.org). It is not a public app or service, and no one else is asked to sign in with it.

## Data accessed

The client requests access to Google Drive so that rclone can list, read, upload and delete files in the owner's Drive.

## How data is used and stored

Files move directly between Google Drive and the owner's computer. No server operated by the owner sits in between, and no data is collected, sold, shared or sent to third parties. The OAuth token is stored only in rclone's configuration file on the owner's machine.

## Google API Services User Data Policy

Use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

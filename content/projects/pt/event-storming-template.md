## 1. Pitch de Elevador

Um template pronto para uso de Event Storming para o Diagrams.net, que acelera workshops de descoberta de domínio e a colaboração entre áreas.

## 2. Problema e Contexto

Sessões de descoberta costumam perder tempo com configuração e consistência visual. Este projeto fornece uma biblioteca reutilizável para começar a modelar imediatamente.

## 3. Escopo e Atuação

- Design da biblioteca visual.
- Publicação com integração direta para o Diagrams.net.
- Manutenção aberta à comunidade e suporte a contribuições.

## 4. Solução Implementada

Uma biblioteca customizada para Draw.io/Diagrams.net, distribuída por URL, construída em torno das práticas de modelagem de Event Storming.

## 5. Stack e Arquitetura

- Template XML para o Diagrams.net.
- Distribuição pública via GitHub.
- Licença MIT.

## 6. Qualidade e Práticas de Engenharia

- Documentação de uso clara.
- Design pensado primeiro para reuso.
- Sinal de adoção pela comunidade (stars/forks).

## 7. Relevância para o Portfólio

Mostra maturidade prática em DDD/Event Storming e capacidade de criar ativos reutilizáveis que melhoram os fluxos de descoberta em equipe.

### Java and PHP Developer | State University of Santa Cruz (UESC)

#### Desafio

Desenvolver sistemas críticos de gestão universitária para dar suporte à administração de pesquisa e aos processos de avaliação acadêmica. Os sistemas precisavam lidar com processamento de dados complexo, integrar com plataformas externas (base curricular Lattes), e atender múltiplas partes interessadas em toda a universidade.

#### Ação

- **Sistema de Gestão de Pesquisa**: Criou o Sistema de Gestão da Pró-Reitoria de Pesquisa e Pós-Graduação usando stack LAMP (Linux, Apache, MySQL, PHP) para centralizar e simplificar os fluxos de gestão de projetos de pesquisa.
- **Sistema de Análise Curricular**: Desenvolveu o Sistema de Análise de Currículos Lattes usando Java para extrair e analisar automaticamente dados dos currículos dos professores, viabilizando avaliação institucional e relatórios.
- **Desenvolvimento Full-Stack**: Trabalhou em tecnologias de backend e frontend para entregar soluções completas atendendo às necessidades administrativas da universidade.

#### Resultado

- Implantou com sucesso o Sistema de Gestão de Pesquisa, centralizando a administração de projetos para toda a Pró-Reitoria de Pesquisa e Pós-Graduação.
- Automatizou a extração e análise de dados curriculares, eliminando o processamento manual dos currículos Lattes do corpo docente.
- Melhorou a eficiência da administração de pesquisa e dos processos de avaliação docente através de soluções de software customizadas.
- Ganhou experiência abrangente com os ecossistemas Java e PHP em ambientes universitários de produção.

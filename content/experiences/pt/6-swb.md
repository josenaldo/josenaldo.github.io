### Java Developer | SWB

#### Desafio

Desenvolver aplicações Java corporativas para clientes diversos, incluindo sistemas de auditoria de banco de dados, plataformas de avaliação de performance, e soluções de faturamento. Os projetos exigiam integração com bancos de dados Oracle, implementação de boas práticas de Java EE, e transferência de conhecimento através de treinamentos e apresentações.

#### Ação

- **Auditoria de Banco de Dados**: Implementou um sistema de auditoria de execução SQL para bancos de dados Oracle usando a tecnologia Oracle Logminer para rastreamento abrangente de atividade do banco.
- **Aplicações Corporativas**: Desenvolveu um sistema de avaliação de performance para a Hewitt usando Struts 2, Spring e Hibernate; criou um sistema de faturamento usando JSP, Servlets e Hibernate.
- **Engenharia de Requisitos**: Modelou requisitos e casos de uso usando Enterprise Architect para documentação estruturada de software.
- **Compartilhamento de Conhecimento**: Ministrou talks técnicos e sessões de treinamento sobre Java SE e EE usando a IDE NetBeans.

#### Resultado

- Entregou com sucesso múltiplas aplicações Java corporativas usando frameworks padrão da indústria (Struts, Spring, Hibernate).
- Implementou uma solução robusta de auditoria de banco de dados, oferecendo rastreabilidade completa de execução SQL para ambientes Oracle.
- Contribuiu para o crescimento da equipe através de treinamento técnico e compartilhamento de conhecimento sobre tecnologias Java.
- Ganhou experiência extensa com padrões Java EE e arquitetura de aplicações corporativas.

### Senior Full Stack Developer | Muvz

#### Desafio

Um grande cliente de jornal precisava modernizar seus serviços Java (EJB) legados para uma arquitetura de microsserviços escalável usando tecnologias modernas. O projeto exigia migrar serviços críticos, implementar integrações orientadas a eventos, e entregar interfaces web modernas, garantindo a entrega no prazo apesar de atrasos iniciais do projeto.

#### Ação

- **Migração para Microsserviços**: Liderou a iniciativa de modernização ao migrar serviços Java (EJB) legados para 5 microsserviços Spring Boot usando Java 17, Spring Security, Spring Data JPA, Spring Cloud OpenFeign e Apache Kafka, melhorando escalabilidade, confiabilidade e velocidade de entrega.
- **Desenvolvimento de Frontend**: Entregou interfaces web modernas usando TypeScript, React, Next.js, React Admin, React Hook Form, TanStack Query (React Query) e MUI, melhorando a experiência do usuário e a manutenibilidade em múltiplas áreas do produto.
- **Plataforma de Back-office**: Construiu uma plataforma de Back-office centralizada (Spring Boot + React Admin) para gerenciar configurações compartilhadas e fluxos operacionais entre microsserviços, melhorando a governança do sistema e reduzindo a sobrecarga operacional.
- **Adoção do Kafka**: Liderou a adoção do Apache Kafka conduzindo o discovery técnico, construindo provas de conceito com Spring, viabilizando o desenvolvimento local via Docker, e conduzindo a prontidão para produção através de decisões de arquitetura colaborativas.
- **Colaboração com DevOps**: Fez parceria com o DevOps para fazer deploy e operar um cluster Kafka no Kubernetes, e construiu múltiplas integrações orientadas a eventos — incluindo um microsserviço de envio de e-mail com logging e auditoria para dar suporte a comunicação assíncrona confiável.
- **Liderança Técnica**: Ofereceu liderança técnica e mentoria reforçando os princípios de Arquitetura Hexagonal, SOLID e DDD em toda a equipe.

#### Resultado

- Modernizou com sucesso o sistema de uma aplicação monolítica baseada em EJB para uma arquitetura de microsserviços, reduzindo custos de manutenção e melhorando a escalabilidade do sistema.
- Melhorou a performance do sistema em mais de 40%, com tempos de resposta mais rápidos e latência menor.
- Eliminou um atraso de projeto estimado em 3 meses, viabilizando a entrega no prazo e uma execução de engenharia mais forte.
- Capacitou a equipe com práticas modernas de engenharia de software através de mentoria em Arquitetura Hexagonal, SOLID e DDD.
- Entregou integrações orientadas a eventos críticas (Kafka, microsserviço de e-mail) com confiabilidade de nível produção.

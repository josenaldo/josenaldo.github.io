Nesta trilha de aprendizado, aprendi programação em Python, dos fundamentos à programação orientada a objetos. O curso abordou a sintaxe do Python e conceitos básicos de programação, tipos de dados (strings, números, listas, tuplas, dicionários, conjuntos), estruturas de controle (if/else, loops, comprehensions), funções e módulos, I/O de arquivos e tratamento de exceções, princípios de programação orientada a objetos (classes, objetos, herança, polimorfismo, encapsulamento), métodos especiais e sobrecarga de operadores, o uso da biblioteca padrão do Python, a organização do código em pacotes e módulos, e boas práticas para escrever código Python limpo. Completei projetos práticos que reforçaram os conceitos e construíram uma base sólida para o desenvolvimento em Python, me preparando tanto para o desenvolvimento de aplicações quanto para o trabalho em data science.

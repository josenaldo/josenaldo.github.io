Neste curso, aprendi:

- **Lendo arquivos**: Introdução à leitura de arquivos, entendimento de encoding, diferentes métodos de leitura, e prática hands-on.
- **Escrevendo arquivos**: Escrita de dados em arquivos, gerenciamento de operações de arquivo com os métodos `close` e `flush`, e iteração sobre arquivos.
- **Boas práticas e exceções**: Tratamento de concorrência, fechamento correto de recursos, gerenciamento de exceções comuns, e uso de context managers (`with`).
- **Entendendo buffers**: Otimização de memória com buffering, escrita eficiente, e tratamento de diferenças de texto entre Python 2 e Python 3.
- **Convertendo contatos**: Conversão de dados CSV para objetos Python, uso de Pickle e JSON, discussão sobre comunicação entre sistemas, e implementação de DAOs para acesso a dados.
- **Conclusão**: Considerações finais sobre manipulação de arquivos em Python.

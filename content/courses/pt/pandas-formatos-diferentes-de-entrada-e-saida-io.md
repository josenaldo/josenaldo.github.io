- **Lendo alunos com JSON**: Configuração do ambiente, leitura de nomes de alunos a partir de JSON, adição de IDs únicos, merge de DataFrames, e o trabalho com JSON tanto localmente quanto na web.
- **Criando cursos a partir de HTML**: Extração de dados de cursos a partir de HTML, modificação de índices e análise da correção dos dados.
- **Escrevendo CSV, JSON e HTML**: Matrícula de alunos, seleção de cursos e exportação de dados em múltiplos formatos, incluindo CSV, JSON e tabelas HTML.
- **Lendo e escrevendo SQL**: Criação e consulta de um banco de dados SQL usando Pandas, tratamento da criação de tabelas e execução de queries SQL.
- **Lendo e escrevendo Excel**: Gerenciamento de dados de alunos no Excel, escrita e leitura de planilhas, e manutenção de planilhas de presença.

Nesta trilha de aprendizado, completei diversos cursos sobre Data Science com Python e Pandas. O curso abordou os fundamentos de Python para data science, NumPy para computação numérica e operações com arrays, Pandas para manipulação e análise de dados (DataFrames, Series, indexação, agrupamento, agregações), técnicas de limpeza e pré-processamento de dados, análise exploratória de dados (EDA) e visualização de dados, o trabalho com diferentes formatos de dados (CSV, JSON, Excel, bancos de dados), análise estatística e estatística descritiva, e a aplicação de fluxos de trabalho de data science a datasets reais. Aprendi a extrair insights de dados, lidar com valores ausentes, realizar transformações e criar visualizações significativas para apoiar a tomada de decisão orientada a dados.

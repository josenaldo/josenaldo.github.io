Neste curso, aprendi:

- **Conhecendo o Jupyter**: Como instalar o Anaconda, configurar um ambiente virtual, e usar o Jupyter Notebook para análise de dados.
- **Importando dados**: Como baixar arquivos, importar datasets para o Pandas, e explorar a estrutura e as informações de um DataFrame.
- **Series e índice**: Como remover duplicatas, aplicar métodos do Pandas, redefinir índices, e criar ou concatenar DataFrames.
- **Filtrando dados**: Como filtrar imóveis residenciais, fazer seleções em um dataset, exportar bases de dados, e organizar DataFrames usando sort_index.
- **Frequências de imóveis**: Como analisar frequências de seleção, trabalhar com diferentes níveis de seleção, e aplicar diversas técnicas de filtragem.
- **Tratando dados ausentes**: Como identificar e remover valores nulos, aplicar tratamentos condicionais, e usar métodos de interpolação para preencher dados ausentes.
- **Novas variáveis**: Como criar novas variáveis, resolver erros na criação de variáveis, e remover variáveis desnecessárias usando diferentes métodos de exclusão.
- **Estatística descritiva**: Como agrupar dados, resumir principais insights, e aplicar estatística descritiva, incluindo a criação de faixas de valores com a função cut().
- **Removendo outliers**: Como detectar e remover outliers usando estatísticas de box plot, filtragem baseada em grupos, e técnicas de visualização de dados com Matplotlib.
